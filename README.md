
# RailSync
## Smart Railway Reservation and Seat Management System

### 1. Project Description
RailSync is a backend-based railway reservation management system developed using MySQL.

It manages train details, passenger information, ticket bookings, cancellations and payments.

### 2. Technologies Used
- MySQL
- MySQL Workbench
- SQL
- Stored Procedures
- Functions
- Cursors

### 3. Main Features
1. Train Management
2. Passenger Registration
3. Ticket Booking
4. Ticket Cancellation
5. Fare Calculation
6. Booking Details
7. Payment Management

### 4. Database Tables
- trains
- passengers
- bookings
- payments

### 5. Project Type
MCA Semester 1 Mini Project

RailSync - Smart Railway Reservation and Seat Management System
