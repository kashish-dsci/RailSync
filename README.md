
# RailSync
## Smart Railway Reservation and Seat Management System

### 1. Project Description

RailSync is a backend-based railway reservation and seat management system developed using MySQL.

The project manages train details, passenger information, ticket bookings, cancellations, seat availability, fare calculation and payment records.

### 2. Project Objectives

- To maintain railway train information.
- To store passenger details.
- To manage ticket bookings.
- To manage ticket cancellations.
- To calculate ticket fares.
- To maintain payment records.
- To track available seats.

### 3. Technologies Used

- MySQL
- MySQL Workbench
- SQL
- Stored Procedures
- Functions
- Cursors

### 4. Database Tables

The project contains four main tables:

1. trains
2. passengers
3. bookings
4. payments
